▶ 回放控制
回放已关闭

回放模式下，命中的请求直接返回已录制的响应，不再执行参数校验或模板渲染。
录制与回放互斥：开启其中一个会自动停止另一个，页面状态同步更新。
建议流程：先录制场景 → 保存文件 → 下次测试时加载 → 开启回放。

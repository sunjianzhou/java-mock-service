格式与 YAML 文件完全相同；应用成功后端点列表自动刷新。
注意：此操作仅修改内存中的配置，服务重启后恢复磁盘文件内容。若要持久化，还需手动同步到 mock-endpoints.yml。

⚠ 格式说明

YAML 必须包含 mock.endpoints 根键，例如：

mock:
  endpoints:
    - id: demo
      method: POST
      path: /demo
      contentType: application/json
      responseContentType: application/json
      responseStatus: 200
      responseBody: |
        {"code":"0"}

每个端点必填：id、method、path 或 pathPattern、responseContentType、responseBody（或 responseBodyFile / responseScript）

回放与录制互斥：开启回放时若正在录制，录制会自动停止（反之亦然）。

建议流程：先录制场景 → 保存 → 下次测试时加载 → 开启回放。
